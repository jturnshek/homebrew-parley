# Security policy

Report suspected vulnerabilities through GitHub's
[private vulnerability form](https://github.com/jturnshek/homebrew-parley/security/advisories/new).
Do not disclose a suspected vulnerability in a public issue.

Useful reports identify the affected Parley version, operating-system version,
installation method, reproducible steps, and security impact. Remove access
tokens, account information, message content, invitation or connection links,
and other private data before submitting evidence.

Public issues are appropriate for ordinary Homebrew installation and upgrade
problems that contain no sensitive information.
